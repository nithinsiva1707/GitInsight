# GitHub Portfolio Analyzer (Frontend Only)

## Instructions to Load:
1. Download and unzip the 'github-portfolio-analyzer.zip' file.
2. Open Google Chrome.
3. Navigate to chrome://extensions/.
4. Enable "Developer mode" in the top right corner.
5. Click "Load unpacked" and select the unzipped folder.
6. Navigate to any GitHub profile page (e.g., https://github.com/torvalds) to see the UI.

Note: This version uses mock data for the UI demonstration.
